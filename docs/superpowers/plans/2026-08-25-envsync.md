# EnvSync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a BigLinux LAN P2P environment sync app (daemon + Electron UI) with group/item selection, mandatory plan confirmation, interactive conflicts, and plugin-based apply for packages/files/env.

**Architecture:** Monorepo with `envsyncd` (systemd user daemon, Node/TS) owning discovery, mutual TLS, inventory, plan, and apply; Electron React UI talks only via local Unix socket JSON-RPC. Shared `catalog` + `protocol` packages; plugins implement `detect` / `diff` / `apply`.

**Tech Stack:** Node 22+, TypeScript, pnpm workspaces, Vitest, Electron, React, mDNS (`@homebridge/ciao` or `bonjour-service`), Node `tls` mutual certs, systemd user unit.

## Global Constraints

- No apply without explicit confirmed plan (spec hard rule).
- LAN only; mutual TLS after fingerprint pairing.
- Sensitive browser paths (cookies/login) opt-in only.
- No `any` in TypeScript.
- Product strings centralized for rename (`envsync`).
- Persist under `~/.local/share/envsync/`.
- Apply order: packages → config files → folders → env; backup before destructive writes.

```typescript
// packages/protocol/src/jsonrpc.ts
export type JsonRpcRequest = {
  jsonrpc: "2.0";
  id: number | string;
  method: string;
  params?: unknown;
};

export type JsonRpcResponse = {
  jsonrpc: "2.0";
  id: number | string;
  result: unknown;
};

export type JsonRpcError = {
  jsonrpc: "2.0";
  id: number | string | null;
  error: { code: number; message: string; data?: unknown };
};

export function encodeJsonRpcRequest(
  id: number | string,
  method: string,
  params: unknown = {},
): string {
  return JSON.stringify({ jsonrpc: "2.0", id, method, params }) + "\n";
}

export function encodeJsonRpcResult(
  id: number | string,
  result: unknown,
): string {
  return JSON.stringify({ jsonrpc: "2.0", id, result }) + "\n";
}

export function encodeJsonRpcError(
  id: number | string | null,
  code: number,
  message: string,
  data?: unknown,
): string {
  return JSON.stringify({ jsonrpc: "2.0", id, error: { code, message, data } }) + "\n";
}

export function parseJsonRpcLine(
  line: string,
): JsonRpcRequest | JsonRpcResponse | JsonRpcError {
  const trimmed = line.trim();
  if (!trimmed) throw new Error("empty jsonrpc line");
  const value: unknown = JSON.parse(trimmed);
  if (typeof value !== "object" || value === null || !("jsonrpc" in value)) {
    throw new Error("invalid jsonrpc");
  }
  return value as JsonRpcRequest | JsonRpcResponse | JsonRpcError;
}
```
